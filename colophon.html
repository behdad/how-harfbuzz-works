Colophon

The text is set in Source Serif 4, the headings in Commissioner, and code in JetBrains Mono.

The pages are built from Markdown by tools/build-site.mjs, with markdown-it. Test fonts are compiled from feature files by fontTools, which also makes the views of their tables. Shaping results and traces come from HarfBuzz 15.1.0, built from source by tools/build-harfbuzz.sh.
